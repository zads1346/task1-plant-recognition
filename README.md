# Plant Recognition Experiments

植物分类实验代码与分析材料，包含 EfficientNet、ConvNeXt、ResNet、DINOv2、前景裁剪、TTA、集成和消融实验入口。

## Contents

- `plant_experiments/plant_study.py`: 主实验脚本
- `plant_experiments/README.md`: 运行说明
- `plant_experiments/test_*.py`: 合同与分支测试
- `植物识别原始代码.txt`: 原始方案记录

真实 Kaggle 数据、模型权重和生成结果未提交。运行前请按脚本中的路径说明准备数据，并安装 PyTorch、torchvision、pandas、scikit-learn、Pillow 和相关依赖。

## Scope

仓库用于课程设计中的实验复现与方法分析。代码中的榜单效果需要在对应 Kaggle 数据和运行环境中重新验证。
